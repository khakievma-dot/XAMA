# XAMA — сетевой портал

Одностраничный сайт-справочник для пользователей сети: где скачать клиент, какие есть протоколы подключения, как решать частые проблемы и ответы на вопросы. Живёт по адресу **[xama.life](https://xama.life/)**.

Весь сайт — это **один файл `index.html`**. Никакой сборки, фреймворков и зависимостей: открыл, поправил текст, залил. Подойдёт всем, кому нужна простая, аккуратная и быстрая страница-справочник, которую легко держать в актуальном состоянии прямо на GitHub.

---

## Что внутри

- **Тёмная и светлая тема** — переключатель в шапке, выбор запоминается в браузере.
- **Вкладки, которые сами собираются** из блоков контента — добавлять и переставлять разделы просто.
- **Адаптив под мобильные** — на телефоне вкладки сжимаются в иконки, активная показывается с подписью. Всё в одну строку, ничего не перекрывает контент.
- **FAQ-аккордеон** — вопросы раскрываются по клику, открыт всегда только один.
- **Превью для мессенджеров** — при отправке ссылки в Telegram / WhatsApp / VK показывается красивая карточка (Open Graph).
- **Ноль зависимостей** — чистый HTML, CSS и немного JS. Из внешнего только шрифты Google Fonts.

## Как развернуть у себя

1. Нажмите **Fork** (или скачайте `index.html` и создайте свой репозиторий).
2. Зайдите в **Settings → Pages** и включите GitHub Pages для ветки `main`.
3. Через минуту сайт будет доступен по адресу `https://ваш-логин.github.io/имя-репозитория/`.

### Свой домен (по желанию)

Если хотите свой адрес вместо `github.io`:

1. Создайте в корне репозитория файл `CNAME` с одной строкой — вашим доменом (например `example.com`).
2. У регистратора домена пропишите DNS-записи на GitHub Pages ([инструкция GitHub](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site)).

## Как редактировать

Проще всего — прямо на GitHub, ничего не скачивая. Откройте репозиторий и нажмите клавишу `.` (точка) — запустится веб-редактор VS Code в браузере. С телефона: замените в адресе `github.com` на `github.dev`.

### Добавить или изменить вкладку

Весь контент разделён на блоки-секции. Панель вкладок сверху **собирается из них автоматически** — руками её трогать не нужно.

Чтобы добавить вкладку, скопируйте целиком один блок и поменяйте три вещи:

```html
<section id="news" class="content-section" data-label="Новости" data-icon="bolt" role="tabpanel" tabindex="0">
  ... ваш контент ...
</section>
```

- `id` — короткое имя латиницей, уникальное;
- `data-label` — название вкладки на кнопке;
- `data-icon` — иконка: `home`, `bolt`, `shield`, `alert` или `help`.

Кнопка вкладки появится сама, в том же порядке, в каком идут секции. Свою иконку можно добавить в объект `TAB_ICONS` внизу файла.

### Добавить вопрос в FAQ

Скопируйте один блок `<details>` и поменяйте текст вопроса и ответа:

```html
<details class="faq-item" name="faq">
  <summary>
    Ваш вопрос?
    <svg class="faq-plus" viewBox="0 0 24 24" aria-hidden="true"><path d="M12 5v14M5 12h14"/></svg>
  </summary>
  <div class="faq-body">
    <p>Ваш ответ.</p>
  </div>
</details>
```

- Атрибут `name="faq"` нужен, чтобы вопросы закрывали друг друга — оставляйте его.
- Нужна кнопка со ссылкой? Добавьте её в тело ответа; сама ссылка живёт в `href`, на кнопке её не видно:
  ```html
  <div class="btn-group">
    <a href="https://t.me/пример" class="btn btn-primary" target="_blank" rel="noopener">Написать в Telegram</a>
  </div>
  ```
  Если ссылка не нужна — просто не добавляйте этот блок.

### Поменять цвета

Все цвета собраны в одном месте — в начале `<style>`, в блоках `:root` (тёмная тема) и `html[data-theme="light"]` (светлая). Меняете переменную — меняется весь сайт.

### Превью-картинка (Open Graph)

За превью в мессенджерах отвечают теги `og:...` в `<head>` и файл `og-image.png` в корне репозитория (рекомендуемый размер 1200×630). Поменяли картинку или адрес — обновите ссылки в тегах.

Мессенджеры кешируют превью. Если старая карточка «залипла», для Telegram есть бот `@WebpageBot` — пришлите ему ссылку, он обновит кеш.
