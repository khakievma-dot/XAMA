# XAMA — сетевой портал

Одностраничный сайт-справочник для пользователей сети: где скачать клиент, какие есть протоколы подключения, как решать частые проблемы и ответы на вопросы. Живёт по адресу **[xama.life](https://xama.life/)**.

Весь сайт — это **один файл `index.html`**. Никакой сборки, фреймворков и зависимостей: открыл, поправил текст, залил. Подойдёт всем, кому нужна простая, аккуратная и быстрая страница-справочник, которую легко держать в актуальном состоянии прямо на GitHub.
